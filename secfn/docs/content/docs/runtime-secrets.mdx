---
title: Runtime Secrets
description: Read secrets from trusted server, CI, build, and local workflows.
---

`@secfn/runtime` is a read-only client for trusted processes. Pass the full hosted SecFn endpoint including the base path:

```ts
import { createSecFnRuntime } from "@secfn/runtime";

const secfn = createSecFnRuntime({
  endpoint: "https://nucleus.example.com/secfn",
  apiKey: process.env.SECFN_RUNTIME_TOKEN!,
  tenantId: "acme",
  environment: "production",
  cache: {
    ttlMs: 60_000,
    staleWhileRevalidate: true,
  },
});

const openAiKey = await secfn.get("OPENAI_API_KEY");
const env = await secfn.toEnv("nucleus-production");
```

## Methods

| Method | Use |
| --- | --- |
| `get(key, options?)` | Resolve one secret. |
| `getSet(name, options?)` | Resolve a named secret set. |
| `preload(keysOrSetNames)` | Warm the runtime cache. |
| `toEnv(secretSetName)` | Convert a secret set to an object for `process.env` or child processes. |
| `toDotEnv(secretSetName)` | Convert a secret set to `.env` text without writing it to disk. |
| `injectEnv(secretSetName)` | Populate `process.env` for the current Node process. |
| `clearCache()` | Drop in-memory cached secrets. |

## Browser Warning

Do not import `@secfn/runtime` into browser bundles for private secrets. Runtime routes return plaintext after successful token verification, so the client belongs in server code, CI jobs, and build scripts only.
