---
title: Secret Sets
description: Group secrets for runtime workloads without granting broad secret access.
---

Secret sets group individual secrets under a named runtime surface such as `nucleus-production` or `stripe-worker`.

```ts
await secfn.vault.createSecretSet({
  name: "nucleus-production",
  tenantId: "acme",
  namespace: "web",
  environment: "production",
  createdBy: "admin",
  members: [
    { secretId: openAiSecret.id, alias: "OPENAI_API_KEY" },
    { secretId: stripeSecret.id, alias: "STRIPE_SECRET_KEY" },
  ],
});
```

Runtime tokens can be scoped to a set:

```ts
await secfn.vault.createServiceToken({
  name: "nucleus-web",
  tenantId: "acme",
  namespace: "web",
  environment: "production",
  scopes: ["set:nucleus-production"],
  createdBy: "admin",
});
```

Set scopes allow resolving the set. Direct secret reads still require `secret:<key>` or `secret:*`.
