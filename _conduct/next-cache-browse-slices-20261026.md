## CacheFn

The V0 source already implements offline queue/reconnect, adaptive priority clearing, bounded fetcher registry and synchronous memoization corrections. Historical Safari blocked statements are superseded by the later native34-check receipt in `browser-matrix-20261023.md:83–87`; that historical run does not prove current settings/availability, offline toggling or performance. Python and distributed caching are expressly outside V0 (`V0_SPEC.md:38–50`), so they must not be invented as new V0 blockers.

**AutoStorage pattern invalidation is an optimization candidate, not an established correctness gap.** `typescript/src/storage/auto-storage.ts:107–118` omits optional `deleteMatching`; `core/cache.ts:475–497` therefore selects keys plus individual deletes even when auto chooses IndexedDB, whereas explicit IndexedDB has the transactional path (`storage/indexeddb-storage.ts:124–165`). V0 pattern target is <50ms/1000 keys (`V0_SPEC.md:892`) and auto fallback is in scope, but the current benchmark measures explicit IndexedDB. The independent diagnostic passed removals, unrelated/foreign namespace preservation and reported count2 while confirming multiple transactions. See `cache-auto-pattern-assessment-20261026.md`. First measure the unchanged workload through public auto mode; only then propose a narrow optimization that preserves failover semantics and does not falsely promise atomicity across localStorage/memory or replay an aborted transaction as success. No Cache implementation change was justified by this assessment.

A second source interleaving worth reproducing, not yet a confirmed contract violation: tag invalidation selects matching keys then separately deletes (`core/cache.ts:448–454`), allowing an intervening retagged replacement to be deleted. V0 requires tag invalidation (`V0_SPEC.md:278–300`) but does not explicitly state linearizability. Establish intended overlapping-write semantics and a deterministic native reproduction before changing the API/storage contract; do not infer distributed guarantees.
