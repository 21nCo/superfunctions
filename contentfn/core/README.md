# @contentfn/core

ContentFn schema, query, patch and envelope types and validators. ESM and CommonJS; Node18.18+ and browser-compatible validation code. Version0.2.0 validates nested fields, array unions and applicable validation rules.

```ts
import { validateSchema } from '@contentfn/core';
const result = validateSchema({ version: 1, documentTypes: [] });
```

See the [complete ContentFn documentation](https://github.com/21nCo/super-functions/tree/dev/contentfn) for contracts, migration details and deployment configuration.
