# @contentfn/admin

The ContentFn administration capability remains folded into CmsFn, with no standalone navigation or operations. Use the CmsFn owner module for its content administration UI. Requires shared admin0.1.5 and Node20+.

See the [complete ContentFn documentation](https://github.com/21nCo/super-functions/tree/dev/contentfn) for contracts, migration details and deployment configuration.
