# @contentfn/cli

The `contentfn` executable supports schema validation/upsert, dataset export/import and document get/patch. Node18.18+; use `contentfn --help`, `--server`, or CONTENTFN_SERVER. Version0.2.0 runs the same commands from the published artifact.

See the [complete ContentFn documentation](https://github.com/21nCo/super-functions/tree/dev/contentfn) for contracts, migration details and deployment configuration.
