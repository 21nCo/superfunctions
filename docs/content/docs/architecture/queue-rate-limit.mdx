```mermaid
flowchart LR
  A[Ingress] --> B[Rate limiter]

```

## Security Caveats

- Enforce tenant-scoped keys and queue names.

## Operational Caveats

- Select algorithm per endpoint: fixed-window, sliding-window, token-bucket.
