# Codex / Droid (and any AGENTS.md-aware tool)

The [AGENTS.md](https://agents.md) convention is supported by Factory's Codex and Droid CLIs as well as several other agentic tools. Drop an `AGENTS.md` at the root of your repo with a section dedicated to authfn.

## Repo-root AGENTS.md

```markdown
# Project Agents

## authfn

When working with `@authfn/*`:

- Mount path is `/auth`.
- Plugins enabled: password, email-otp, social-oauth (Google), 2FA, api-keys.
- Database is Postgres via Drizzle.
- The schema is generated by `npx @superfunctions/cli generate-schema --config ./superfunctions.config.mjs --adapter drizzle --dialect postgres --output ./apps/api/src/db/generated --force` and lives in `apps/api/src/db/generated/authfn-schema.ts`.

Authoritative docs: https://authfn.com/docs
For a full-text RAG file: https://authfn.com/docs/llms-full.txt
```
