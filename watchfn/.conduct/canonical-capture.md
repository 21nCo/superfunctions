# Canonical browser capture and bug reports

2026-10-20 checkpoint. `BrowserClient.capture(event: Record<string, unknown>): Promise<void>` now snapshots arbitrary canonical JSON objects into the existing bounded delivery queue. It bypasses DOM checks and RUM sampling. It waits for the accepted snapshot's HTTP acknowledgment, including when admission races the final microtasks of a preceding drain. Admission and exhausted/terminal delivery failures reject; failed batches remain available to explicit flush/close retry. Existing track behavior remains sampled browser collection.

HTTP ingestion accepts `type: "bug_report"` without requiring a synthetic event name. Validation covers nonempty id, app.name, sessionId and report.title; ISO timestamp; supported severity; object context; and supplied optional app/report/attachment/user/integration/replay fields. The validated input itself is persisted without schema transformation or wrapping. Other event types retain existing name validation, batch limits and64KiB per-event limits. Authentication and complete-batch validation precede persistence.
