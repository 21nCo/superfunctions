# @superfunctions/reviewfn-cli

Installs the `reviewfn` binary. Commands: `init` (`--panel` writes a panel policy template), `preflight`, `review`, `panel`, `report` (`--panel` re-renders a stored panel report), `publish`, `render`, and `evaluate`. See [panel review](../docs/panel.md) for `reviewfn panel`, its exit codes and its optional harness adapter packages. Run from a Git worktree with Node.js 22 or newer.
