### **datafn/server/src/execution/query/execute.ts - Performance**
**📁 File:** `datafn/server/src/execution/query/execute.ts`

#### **Issue 1:** In-Memory Query Execution Scalability *(Qodo Code Review)*
- **Severity:** Medium
- **Description:** The current architecture loads data into memory (`DbDataStore`) and performs filtering/sorting in-process. This is not scalable for large datasets and is an "architectural flaw" for a production server.
- **Location:** QueryEngine architecture
- **Fix:** Push filtering and sorting down to the database adapter level (SQL generation) instead of fetching all records.

#### **Issue 2:** N+1 Query Problem *(Qodo Code Review)*
- **Severity:** Medium
- **Description:** The code likely iterates over results and calls `findOne` for relations, causing N+1 database queries.
- **Location:** Relation expansion logic
- **Fix:** Use `findMany` with `where: { id: { in: [...] } }` to batch fetch related records (DataLoaer pattern).
