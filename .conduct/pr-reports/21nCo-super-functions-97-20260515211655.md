### **apifn/collections/src/runner/script-sandbox.ts - Async Timeout Enforcement**
**📁 File:** `apifn/collections/src/runner/script-sandbox.ts`

#### **Issue 1:** Async collection scripts can hang indefinitely *(Codex)*
- **Severity:** High
- **Location:** Line 165
- **Description:** The VM timeout only applies to synchronous `runInContext` execution. Because scripts run inside an async IIFE, a script that awaits a never-settling promise can block the runner indefinitely.
- **Fix:** Race the returned promise against a host-side timeout and reject when the timeout elapses.

#### **Issue 2:** Async collection scripts can hang indefinitely *(Gemini Code Assist)*
- **Severity:** High
- **Location:** Line 165
- **Description:** Gemini reported the same async timeout gap: `runInContext` returns a promise before timeout enforcement can protect awaited async work.
- **Fix:** Use `Promise.race` with a host-side timer for every user-provided script execution.
