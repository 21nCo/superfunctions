## Overview

The DataFn Python SDK provides the same query, mutation, transaction, and sync protocol as the TypeScript server, implemented for Python server-side applications. It supports any ASGI-compatible framework (FastAPI, Starlette, etc.).

## Installation

```bash
pip install datafn
```

## Package Structure

```
datafn/
  __init__.py          # Package exports
  server.py            # create_datafn_server factory
  db.py                # Database adapter protocol
  envelope.py          # Envelope types and helpers
  validation.py        # Schema and payload validation
  filters.py           # Filter evaluation
  guards.py            # Mutation guards
  idempotency.py       # Idempotency tracking
  transaction.py       # Transaction execution
  relations.py         # Relation handling
  change_tracking.py   # Sync change tracking
  constants.py         # Shared constants
  handlers/
    query.py           # Query handler
    mutation.py        # Mutation handler
    transact.py        # Transaction handler
    sync.py            # Seed, clone, pull, push handlers
```

## Protocol Compatibility

The Python SDK implements the same DFQL wire protocol as the TypeScript server. Clients built with `@datafn/client` can connect to either a TypeScript or Python server without changes. All endpoints accept and return identical JSON envelope structures.
