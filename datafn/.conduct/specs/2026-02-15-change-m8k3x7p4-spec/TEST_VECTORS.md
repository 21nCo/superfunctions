# Test Vectors

## Overview

This document defines concrete test vectors for the unified schema generation and join table refactor. Each test vector specifies inputs, expected outputs, and verification criteria.

---

## TV-DRZ-PG-001: Generate Drizzle Schema — Postgres Full Types

**Requirement Coverage**: FR-DRZ-PG-001, FR-MOD-REQ-001, FR-PK-001, FR-EXPORT-001, FR-HEADER-001, FR-COLNAME-001

**Input Schema**:
```typescript
{
  resources: [
    {
      name: "task",
      version: 1,
      fields: [
        { name: "id", type: "string", required: true, unique: true },
        { name: "title", type: "string", required: true },
        { name: "done", type: "boolean", required: false, default: false },
        { name: "priority", type: "number", required: false },
        { name: "createdAt", type: "date", required: true },
        { name: "metadata", type: "object", required: false },
        { name: "tags", type: "array", required: false },
        { name: "avatar", type: "file", required: false },
      ],
    },
  ],
  relations: [],
}
```

**Function Call**:
```typescript
generateDrizzleSchema(schema, "postgres");
```

**Expected Output**:
```typescript
// Generated by @datafn/cli. DO NOT EDIT.
// Database: postgres

import { pgTable, text, boolean, numeric, bigint, jsonb } from "drizzle-orm/pg-core";

export const task = pgTable("task", {
  avatar: text("avatar"),
  createdAt: bigint("created_at", { mode: "number" }).notNull(),
  done: boolean("done").default(false),
  id: text("id").primaryKey(),
  metadata: jsonb("metadata"),
  priority: numeric("priority"),
  tags: jsonb("tags"),
  title: text("title").notNull(),
});

export const schema = { task };
```

**Verification**:
- All 7 DataFn field types correctly mapped to Postgres Drizzle types
- `id` field has `.primaryKey()`
- `required: true` fields have `.notNull()`
- `default: false` generates `.default(false)`
- `createdAt` → `"created_at"` (snake_case SQL column)
- Fields sorted alphabetically
- `schema` export includes all tables
- Header comment present

## TV-DRZ-MOD-001: Field Modifiers — Required, Unique, Default

**Requirement Coverage**: FR-MOD-REQ-001, FR-MOD-UNQ-001, FR-MOD-DEF-001

**Input Schema**:
```typescript
{
  resources: [
    {
      name: "user",
      version: 1,
      fields: [
        { name: "id", type: "string", required: true, unique: true },
        { name: "email", type: "string", required: true, unique: true },
        { name: "name", type: "string", required: true },
        { name: "role", type: "string", required: false, default: "member" },
        { name: "score", type: "number", required: false, default: 0 },
        { name: "verified", type: "boolean", required: true, default: false },
      ],
    },
  ],
  relations: [],
}
```

**Function Call**:
```typescript
generateDrizzleSchema(schema, "postgres");
```

**Expected Content** (user table body):
```typescript
export const user = pgTable("user", {
  email: text("email").notNull().unique(),
  id: text("id").primaryKey(),
  name: text("name").notNull(),
  role: text("role").default("member"),
  score: numeric("score").default(0),
  verified: boolean("verified").notNull().default(false),
});
```

**Verification**:
- `email` has both `.notNull()` and `.unique()`
- `id` has `.primaryKey()` (unique implied by PK, no separate `.unique()`)
- `role` has `.default("member")` without `.notNull()`
- `score` has `.default(0)`
- `verified` has both `.notNull()` and `.default(false)`

## TV-DRZ-IDX-001: Index Generation

**Requirement Coverage**: FR-IDX-001

**Input Schema**:
```typescript
{
  resources: [
    {
      name: "event",
      version: 1,
      fields: [
        { name: "id", type: "string", required: true },
        { name: "type", type: "string", required: true },
        { name: "createdAt", type: "date", required: true },
        { name: "userId", type: "string", required: true },
      ],
      indices: { base: ["type", "createdAt"], search: ["type"] },
    },
  ],
  relations: [],
}
```

**Function Call**:
```typescript

```

**Expected Output** (relevant section):
```typescript
import { pgTable, text, bigint, index } from "drizzle-orm/pg-core";

export const event = pgTable("event", {
  createdAt: bigint("created_at", { mode: "number" }).notNull(),
  id: text("id").primaryKey(),
  type: text("type").notNull(),
  userId: text("user_id").notNull(),
}, (table) => [
  index("event_type_idx").on(table.type),
  index("event_created_at_idx").on(table.createdAt),
]);
```

**Verification**:
- `index` imported from `drizzle-orm/pg-core`
- Two indices generated for `base: ["type", "createdAt"]`
- `search` index NOT generated (comment or ignored)
- Index names follow `{table}_{field}_idx` convention
- Indices reference `table.fieldName` (camelCase property name)

## TV-DRZ-JOIN-002: Join Table with Metadata and Custom Names

**Input Schema**:
```typescript
{
  resources: [
    {
      name: "users",
      version: 1,
      fields: [{ name: "id", type: "string", required: true }],
    },
    {
      name: "roles",
      version: 1,
      fields: [{ name: "id", type: "string", required: true }],
    },
  ],
  relations: [
    {
      from: "users",
      to: "roles",
      type: "many-many",
      relation: "assignments",
      joinTable: "user_roles",
      joinColumns: { from: "userId", to: "roleId" },
      metadata: [
        { name: "grantedAt", type: "date" },
        { name: "grantedBy", type: "string" },
      ],
    },
  ],
}
```

**Function Call**:
```typescript
generateDrizzleSchema(schema, "postgres");
```

**Expected Output** (join table):
```typescript
export const user_roles = pgTable("user_roles", {
  grantedAt: bigint("granted_at", { mode: "number" }),
  grantedBy: text("granted_by"),
  id: text("id").primaryKey(),
  roleId: text("role_id").notNull(),
  userId: text("user_id").notNull(),
});
```

**Verification**:
- Custom table name `user_roles` (from `joinTable`)
