## Outcome

`@uifn/core` now exposes canonical controllers for AlertDialog, Dialog, Drawer, FloatingPanel, HoverCard, Popover, Tooltip, and Tour. They share one immutable overlay policy substrate while retaining different modal, focus, dismissal, interaction, naming, portal, presence, and positioning rules. Core owns state and policy only: it does not read browser globals or implement focus trapping, outside classification, scrolling, portals, presence, timers, or geometry.

`@uifn/dom` now has one overlay binding that executes those policies through the Phase 05 layer stack, focus scopes, modal isolation and scroll locking, portal, presence, positioning, and scoped resource ownership. Focus scopes and portals gained explicit branch support so nested content portaled into a ShadowRoot remains inside the parent overlay for both focus and outside-interaction classification.

The real-browser harness exercises all eight primitives, a menu → popover → dialog stack, portaled Shadow DOM, close/reopen, removed triggers, abrupt teardown, touch behavior, focus restore, semantics, and geometry. Chromium, Firefox, WebKit, Pixel 7 Chromium, and iPhone 13 WebKit projects pass. Every recorded DOM resource total is zero.

The authoritative gate passes, including the full stable aggregate. This is development evidence from a dirty tree; it does not claim the exported React/Svelte/Solid compound adapters or the overall ecosystem are already 10/10. Those adapters and the independent accessibility/release evidence remain assigned to later phases.

## Core and DOM ownership

The core overlay base provides:

- controlled and uncontrolled open state;
- immutable primitive policy identity;
- pending open/close-delay state without scheduling browser timers;
- interaction-source and dismissal reasons;
- stable IDs, state, parts, actions, callbacks, and destroy lifecycle;
- pure accessible-name and AlertDialog dismissal validators.

The DOM overlay binding exclusively provides:

- top-layer outside interaction and Escape routing through `platform.layers`;
- trapping, autofocus, restoration, fallback, and portaled branches through `platform.focusScopes`;
- modal isolation and reference-counted scroll locking through `platform.modals`;
- shared positioning and lifecycle updates through `createUIFnPositioner`;
- one physical portal node through `createUIFnPortal`;
- interruptible visibility through `createUIFnPresence`;
- hover-delay timers and every related listener/observer through the shared resource scope.

The core source verifier rejects browser globals, local timeout scheduling, legacy overlay model factories, positioning, presence, and local focus behavior. The DOM platform scan inspected 212 production files and found zero prohibited ownership violations. Existing framework adapters are not represented as migrated public compounds by this phase; Phases 11–13 must bind these same controllers and services without reintroducing local behavior.
