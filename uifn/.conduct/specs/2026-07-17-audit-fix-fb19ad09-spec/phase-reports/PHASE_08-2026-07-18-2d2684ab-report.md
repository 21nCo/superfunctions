Every controller uses stable collection identity, canonical command resolution, shared repair, shared typeahead, and immutable part contracts. The old `DropdownMenu`/`MenuBar` controller variants and local model paths were removed as a pre-1.0 clean break; the reviewed public core constructors are `createMenuController` and `createMenubarController`.

In particular, RTL Menubar `ArrowDown` remains `open-first`; only logical horizontal movement is mirrored. Tree hierarchy movement is also logical, so the expand direction mirrors without changing vertical traversal.

Dynamic insert, removal, reorder, disable, controlled changes, nested items, registration, and async tree loading converge through stable keys and deterministic repair. Removing the active item chooses the same logical slot where possible, then a valid enabled fallback. Controlled controllers request repair without silently mutating the controlled value. No controller derives durable identity from DOM position.

`@uifn/dom` executes the browser work through the existing Phase 05 and Phase 07 services: layers, focus scopes, position, portals, presence, resource tracking, DOM roving focus, pointer-grace geometry, delayed pointer intent, and touch long-press. ## Canonical keyboard model

| Primitive | Region/model | Canonical behavior |
| --- | --- | --- |
| ContextMenu | vertical content plus logical submenu axis | Up/Down traverse enabled items; Home/End bound the collection; Enter/Space activate; logical forward opens a submenu; logical backward/Escape closes and returns focus; locale-aware typeahead is enabled. |
| Menu | vertical content plus logical submenu axis | Same content model as ContextMenu, with trigger-owned open state, disabled skipping, nested submenu path, pointer grace, and trigger/parent focus return. |
| Menubar | logical-horizontal root plus vertical content | Root forward/backward mirrors in RTL; root Down/Up always open first/last and never mirror; content Up/Down remain vertical; Escape closes and restores trigger focus. |
| NavigationMenu | orientation-aware root plus logical content exit | Horizontal roots mirror in RTL, vertical roots use Up/Down, Home/End target bounds, activation opens content or follows links, and delayed pointer intent is a DOM-owned resource. |
| Pagination | logical-horizontal native navigation | Logical arrows and PageDown/PageUp change page, Home/End target bounds, Enter activates the focused page, and page/count changes clamp deterministically. |
| Tabs | orientation-aware root | Horizontal arrows mirror in RTL; vertical tabs use Up/Down; Home/End target bounds; automatic activation follows focus while manual activation waits for Enter/Space. |
| TreeView | vertical visible collection plus logical hierarchy | Up/Down traverse visible enabled nodes; logical forward expands or enters the first child; logical backward collapses or returns to the parent; Home/End bound the visible tree; Enter/Space select. |

Adapters and DOM bindings consume controller actions and commands; they do not reinterpret these keys. A mismatch between an observed and expected command fails with `UIFN_KEYBOARD_MODEL_DIVERGED`.

## Collection and repair model

The canonical navigation substrate provides:

- stable string/number collection keys independent of DOM order;
- nested parent/child identity and visible-tree flattening;
- enabled-item traversal, looping policy, orientation, and direction;
- locale-aware bounded typeahead with one shared implementation;
- register, unregister, replace, reorder, and disable transitions;
- prior-index repair that prefers the same logical slot and then a valid enabled fallback;
- separate active/focused, selected, expanded, open, and controlled-request state;
- explicit repair requests for controlled state rather than hidden mutation;
- immutable snapshots, actions, parts, callbacks, IDs, and destroy lifecycle.

Controller-specific consequences are covered directly:

- Menu and ContextMenu prune invalid submenu paths when ancestors disappear.
- Menubar repairs a removed or disabled root and keeps open-menu focus coherent.
- NavigationMenu repairs active triggers and preserves delayed-intent ownership in DOM.
- Pagination clamps the current page when count or page size shrinks.
- Tabs repairs focused identity and selected identity according to controlled/uncontrolled mode.
- TreeView repairs focus, selection, expansion, ARIA position metadata, and visible hierarchy when nodes change; async child loading feeds the same collection path.

The contract verifier rejects local collection, typeahead, roving-focus, keyboard-map, timer, or browser-global behavior in core. Legacy `dropdown-menu.ts` and `menu-bar.ts` sources are required to be absent.

## DOM ownership and submenu behavior

`uifn/dom/src/navigation.ts` provides three shared bindings and one pure geometry helper:

- `createUIFnMenuDomBinding` owns menu layers, focus return, position, portals, presence, context-menu long press, submenu intent, and tracked listeners/timers.
- `createUIFnNavigationMenuDomBinding` owns delayed pointer intent and the shared overlay services for NavigationMenu.
- `createUIFnRovingFocusDomBinding` projects controller focus identity into actual DOM focus without redefining navigation policy.
- `isUIFnPointInPointerGraceTriangle` provides the canonical submenu pointer corridor.

Pointer movement into a submenu preserves the open path only while the pointer remains inside the computed grace triangle. Leaving the corridor closes the submenu. Keyboard logical-forward opens and focuses the first enabled child; logical-backward closes and returns focus to its parent trigger. Escape returns to the owning trigger. Touch hover is ignored, while a completed long press opens ContextMenu. Every listener, observer, delay, portal, layer, focus scope, presence object, and positioner is scoped and released on teardown.

`applyUIFnPartProps` also restores the element's prior attributes, properties, and listeners when a binding is released, which prevents stale semantics or event handlers across reactive adapter rerenders.
