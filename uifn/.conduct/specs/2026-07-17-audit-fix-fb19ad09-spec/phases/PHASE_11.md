# PHASE_11 — Complete React adapter and compound API

## Objective

Deliver Base/Radix-quality React compound composition for every stable primitive without owning behavior.

## Entry

- Phases 06–10 canonical logic/parts/DOM traces pass.
- React public composition conventions have a focused API/type review.

## Requirements

- `REACT-001`.

## Work

1. Generate/implement typed hooks, contexts, providers, and every anatomy part for all 61 catalog primitives from public controllers/DOM bindings.
2. Support documented `asChild`/render composition, ref forwarding, event/ref/prop merging, controlled/uncontrolled callbacks, portal/presence, forms, and open composition without cloned behavior.
3. Remove local React Accordion/ContextMenu/Dialog/selection/focus/layer/position/timer logic and any generic factory used as a substitute for a required compound.
4. Prove React 18.3 and 19 StrictMode, concurrent transitions, Suspense, streaming SSR/hydration, ID stability, portal hydration, form reset, abrupt unmount, and error-boundary cleanup.
5. Validate public API extraction, peer ranges, tree shaking, and both package/source consumers.

## Required evidence

- `TV-REACT-001-P/N` plus every applicable primitive vector mounted through actual public React compounds.
- Zero unexpected console/act/hydration warnings; test environment limitations are not accepted as passing browser evidence.
- Seeded local-state/ref loss mutations are caught by intended gates.

## Exit gate

React inventory exactly matches catalog anatomy/features, React owns no behavior fork, and all public trees reproduce golden semantic traces under supported React versions.

## Do not

- Do not mirror DOM state into local React state except framework rendering synchronization owned by adapter-kit.
- Do not use test-only sidecars to satisfy form/overlay/interaction assertions.

## Handoff

Phase report records API/type snapshots, framework-specific justified exceptions, exact React versions, and trace/evidence paths.
